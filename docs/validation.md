# v0.3 検証記録

## 自動テスト

`npm run build` はTypeScriptチェックとViteの静的ビルドです。`npm test` は単体55件とブラウザ52件を実行します。

- 単体：時計と休止、通常死亡／家禽の気絶、連打と防御、全8エリアへの徒歩到達性、12人の日課、96話題、任意メモと削除、未記録依頼の再質問1回、納品・期限、信頼上限、睡眠・空腹・風邪、採集・強化切れ・中断、釣りの餌と耐久・強化による魚種不変、工房の営業時間とFIFO、取消し・在庫・売却、転移杭・探索霧・結末・完全な保存巻き戻し、旧v1保存移行、ゲームパッド入力。
- ブラウザ（PC／iPhone相当の画面・タッチ設定）：初期描画と黒画面時の案内、移動・タッチ解除・縦横表示、村と草原の往復、導入から自宅に入り睡眠→保存→再読込、JSON書出し／読込、戦闘死亡と復元、会話からメモを残す／残さない／削除、料理試作、釣り、工具の破損、地図切替、商店と工房、強化と属性付与、二つの結末、オフライン再訪、ゲームパッドの切断。

新規開始から自宅睡眠・保存までは画面の移動操作で実行します。特定の場所・在庫が必要な個別機能は、正規のJSON読込を使ったテスト用の保存状態から開始します。これは数時間をかけた新規ゲーム全体の手動プレイの代わりではありません。

## 実機で確認する流れ

1. HTTPSで公開したビルドをiPhone Safari／Android Chromeで開く。黒画面にならず主人公が表示される。
2. 十字キーの長押し、斜めの複数押し、指離し、指を画面外へ動かす、画面回転後の再操作を確認する。
3. ダン→採集→模擬戦→村長→家畜小屋→睡眠→手動保存→終了／再読込を完走する。
4. 戦闘とメモを開いた状態、釣りと採集中、保存直後にホームへ戻って復帰する。時計や敵が休止分だけ一気に進まない。
5. JSONを端末のファイルに書き出し、再読込して位置・所持品・時刻が戻る。ブラウザの保存拒否時には説明が表示される。
6. キャッシュ準備後に機内モードで再訪し、タイトルと移動が動く。ブラウザがデータを消去した場合はオンラインで再取得する。

## 配布

`dist/` は静的ファイルのみです。ゲームを更新する時はビルド全体を一緒に配置します。Service Workerの更新は既存ページを閉じて再度開いた際に有効になります。`main` へのマージやサイトの公開は開発ブランチへのpushとは別操作です。
