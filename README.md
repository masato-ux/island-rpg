# 無詠唱の魔法使い — OFFICE REBIRTH

声と魔力を失った勇者一行の魔法使いが、勇者の最後の転生魔法で現代のオフィスへ辿り着く2Dゲームです。今回の実装範囲は、新しい物語の導入と、画像を参考にしたオフィス内の探索です。

## 遊び方

トップページで「物語を始める」を押すと、魔王城→勇者の転生魔法→現代のオフィスの順に導入を読み進められます。「オフィスから始める」では探索から開始できます。

- 矢印キー / WASD、または画面の十字ボタンで移動。Shiftで早歩き。
- E / Space、または「調べる」で近くの机・同僚・給湯設備を調べます。
- 「全体表示」「拡大して追従」で表示範囲を切り替えます。スマートフォンでは追従表示から開始します。
- 「記録する」で現在地をこの端末のブラウザに保存。「続きから」で再開します。

オフィスには応接室、8人掛けの会議室、個室、12席の執務机、休憩スペース、自動販売機、給湯カウンター、ウォーターサーバーを配置しています。壁・机・椅子・立っている人物には当たり判定があり、部屋同士は通路で接続します。主人公の声と魔力は戻っていません。

## 開発

Node.js 24を使用します。

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run test:unit
npx playwright test tests/office.spec.js
```

ブラウザ検証にはChromiumが必要です。未インストールの場合は `npx playwright install --with-deps chromium` を実行してください。`npm test` は新オフィスと保存してある旧島版を両方検証します。

## 構成

- `src/office-model.ts`: オフィスの配置・衝突・移動。
- `src/office-art.ts`: オリジナルのドット絵による家具・設備・人物・フロアの描画。
- `src/office.ts`: 導入、キーボード・タッチ・ゲームパッド入力、カメラ、会話、端末内保存。
- `index.html` / `office.css`: 新しいゲームの入口。

旧島版は `island.html` に保存してあります。旧版のセーブデータと新オフィスの現在地は別の保存キーを使います。旧版の説明は [島版の記録](README-island.md) に残しています。通常の公開URLは新オフィスを表示します。

GitHub Pagesは `feat/browser-rpg-foundation` または `main` へのpushでビルド・検証後に配信します。実機iPhone Safariと物理ゲームパッドでの最終確認は別途必要です。
