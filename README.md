# Island RPG

スマートフォンとPCのブラウザで動く2Dドット絵RPGの第1段階です。島と主人公をCanvas 2Dで描画し、草原を探索できます。外部画像・フォント・CDN・WebGL・APIキーは不要です。

> 仕様書はこの作業環境では確認できていないため、舞台・主人公・画面は仮実装です。戦闘、会話、セーブ、音声は次の段階で実装します。

## 起動

Node.js 24以上を推奨します。ゲーム本体には外部依存がなく、起動だけならインストール不要です。

```sh
npm start
```

サーバーは全インターフェースのポート5173で待ち受けます。`PORT=8080 npm start` で変更可能です。スマートフォンから確認する場合は、同じネットワークのPCのIPアドレスとポートを指定するか、静的ホスティングへ配置してください。開発サーバーには認証機能がありません。

- PC：矢印キー、WASDで移動
- スマートフォン：画面の十字ボタンを長押し
- 海と木：通行不可
- 「スタート位置へ」：主人公の位置をリセット

タッチにはPointer Eventsを使用し、指を離す／キャンセルする／タブを離れる際に操作を解除します。描画解像度を384×256に固定し、CSSで拡大して高DPI端末の描画負荷を抑えています。画面回転時もCanvasの描画バッファを再生成しません。初期化失敗時とJavaScript無効時には説明を表示します。

## ビルドとテスト

```sh
npm ci
npm run build
npx playwright install chromium
npm test
```

このクラウド環境では `/usr/bin/chromium` を利用するためブラウザの追加インストールは不要です。別のブラウザバイナリは `CHROMIUM_PATH` で指定できます。`npm test` は `dist/` のサーバーを起動し、デスクトップとiPhone相当の画面・タッチ設定で計6件を実行します。

確認対象：明るい描画ピクセルと色数、主人公の移動、海岸の衝突、リセット、タッチ長押しと解除、キャンセル、縦横表示、フォーカス／可視状態変更後の操作停止、Canvas初期化失敗の案内。スクリーンショットは `test-results/` に生成します。Chromiumによるエミュレーションであり、実機Safari／Androidの動作保証ではありません。公開前に両実機で縦横回転、ホーム画面からの復帰、長押しと指離しを確認してください。

```sh
node scripts/server.mjs --dist
```

ビルド後の `dist/` は任意の静的ホスティングに配置可能です。相対パスを使用しており、GitHub Pagesのリポジトリ配下でも動作します。

## GitHubへの反映

コード、ロックファイル、テスト、ビルドスクリプトをGit管理します。`node_modules/`、`dist/`、テスト結果は含めません。変更を確認して作業ブランチをpushし、`main` へのPull Requestを作成してください。

```sh
git push origin HEAD:feat/browser-rpg-foundation
```

この手順はコードの反映です。Webへの公開は静的ホスティング側で別途設定します。
