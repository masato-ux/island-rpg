# 新しい物語と第1段階の実装

主人公は勇者一行の魔法使い。魔王との戦いで声と魔力を失う。主人公を救うため、勇者は残るありったけの魔力を使って転生魔法を発動する。主人公が目を覚ました場所は現代のオフィス。声も魔力も戻らないまま、新しい世界を歩き始める。

勇者のその後や転生の理由の全貌、オフィスでの仕事や物語の結末は今回確定していません。今回遊べるのは導入とオフィスの自由歩行、近くの設備や同僚への短い反応です。旧島版の生活・戦闘・依頼システムは、新オフィスの進行には接続していません。

添付画像のオフィス部分を参考に、上段に応接室・会議室・個室、中央から下に2列の執務机、右側に休憩・給湯設備を置いています。広告・検索欄・SNSのボタンや人物など、オフィス外の要素はゲーム画面に含めていません。画像を貼った背景ではなく、家具・設備ごとの描画と当たり判定を持つフロアです。
