# 無詠唱の漂流者 v0.3

PC・スマートフォンのブラウザで動く、日本語の見下ろし2D RPGです。[仕様書v1.0](docs/rpg_spec_v1.md)を基に、漂着から島での暮らし、探索、祭壇での選択までをつないだ初期版です。課金・アカウント・サーバーAPIはありません。

## はじめに

「最初から」で南海岸へ漂着します。すぐ東のダンに近づいて「調べる」。紙とペンを受け取り、北の道沿いの草を採ってから、西の家畜小屋近くのダンへ戻ります。家禽との一度だけの模擬戦を終え、村長宅前のロアンから魔法の袋と魂の楔を受け取ってください。

メニューの「魂の楔で保存」で現在の世界を保存できます。畜産家の家畜小屋が自宅です。入口を調べて入り、奥で調べると睡眠と料理ができます。日中、入口に住人がいる建物は会話画面の「○○に入る」から入れます。

最北部の祭壇へは、村→草原→南部森林→中央森林→北部山岳→最北部と主道をたどって到達できます。西の岩場、東の湖からも山へ進めます。必須ボス、関所、信頼値の条件はありません。祭壇でどちらの選択をしても、その後の島の暮らしは続きます。

## 遊べること

- 屋外8エリアと既存建物6室内、カメラ追従・衝突・短いフェード。320×180・16pxドット絵、Canvas 2Dで画面内のみ描画。
- 12人の日課、96話題、固定選択式の会話、身振り、任意のメモ・話者フィルタ。人物情報は残っているメモに基づきます。
- 見える範囲の探索記録、詳細図と島全体図、各地に1本の転移杭。
- 通常敵6種と古竜の影。徘徊・警戒・追跡・帰巣・逃走、最大3体の群れ。戦闘中も敵は独立して攻撃し、攻撃・防御・逃走・薬・魔法が使えます。
- 装備5部位、12種類の段階別工具、耐久・修理、通常強化と火／水／雷の属性付与、HP／MP／剣術／魔法制御の成長。
- 固定資源の採集と再生、釣りと餌・魚影、素材の鑑定。処理中は中断でき、敵が近づくと早送りが落ちます。
- 空腹・疲労・濡れ・風邪、料理と試作、自宅の1〜7時間睡眠、時間帯と天候。
- 店の営業時間・毎日の在庫、まとめ売りの総額確認、素材と代金を前払いする工房FIFO、修理、未着手の取消し、完成品受け取り。
- NPCの依頼・期限・報告・辞退、贈り物と信頼、子供の鬼ごっこ／かくれんぼ。依頼一覧画面はなく、受諾時にメモした依頼だけメモに記録されます。
- 二つの結末、死亡時の完全巻き戻し、二世代のチェックサム付き保存、JSON輸出入。
- キャッシュ準備後のオフライン再訪。初回はオンラインが必要で、HTTPS／localhostとService Workerが利用できるブラウザが対象です。

## 操作

| 操作         | キーボード                      | タッチ／ゲームパッド                 |
| ------------ | ------------------------------- | ------------------------------------ |
| 移動         | WASD・矢印                      | 左下十字キー／左スティック・十字キー |
| 走る・忍び足 | Shift・Alt                      | 右下で切替／RB・LB                   |
| 調べる・決定 | Z・Enter                        | 調べる／A                            |
| 戻る         | X・Escape                       | やめる・閉じる／B                    |
| メニュー     | C                               | メニュー／X                          |
| 地図・メモ   | M・J                            | メニュー内／Yで地図                  |
| 身振り       | Tab（フィールドにフォーカス時） | 住人の会話画面                       |

ボタンはTabでフォーカスしてEnterでも操作できます。ゲームパッドの表記は標準マッピングです。戦闘コマンドはボタンでも操作します。メニュー・メモ・会話・地図・店舗を開いても時間は進みます。

## 保存について

保存はこのブラウザの端末内です。ブラウザのデータ削除で失われるため、JSONも書き出して保管してください。JSON読込は現在の進行を置き換え、保存スロットも更新します。「最初から」だけでは既存の保存は消えません。

保存バージョン2では、時刻と乱数、位置と向き、能力・XP、装備と強化期限、所持品順序、NPC信頼・贈与、依頼・メモ、素材知識、資源・魚影、在庫・工房、転移杭・探索霧、魔物・天候・生活状態・結末を保存します。v1の保存も不足分を初期化して読み込めます。戦闘中は保存できません。採集・釣り・子供と遊んでいる途中や、メモを取るか選んでいる途中も、進行状態とともに保存・再開できます。

## 開発とテスト

Node.js 24.19以上を推奨します。

```sh
npm ci
npm start
```

Viteが全インターフェースの5173番で起動します。スマホ実機からは同じネットワークのPCのIP／ポート、または静的ホスティングへアクセスしてください。開発サーバーには認証がありません。

```sh
npm run build
npx playwright install chromium
npm test
```

クラウド環境では `/usr/bin/chromium` を利用するため追加のブラウザインストールは不要です。`CHROMIUM_PATH` で任意の実行ファイルを指定できます。テストは単体48件とPC／iPhone相当のChromiumによるブラウザ48件です。ブラウザテストはビルド済み `dist/` を5180番で配信するため、先にビルドしてください。結果とスクリーンショットは `test-results/` に生成されます。

GitHub Actionsにも同じビルド・テストを定義しています。クラウドでの検証とGitHub Actions上の実行結果は別です。

コード整形：`npm run format`、確認：`npm run format:check`。

## 構成

- `src/state.ts`・`maps.ts`：移動・地形と接続
- `src/session.ts`：時計・戦闘・導入・保存スナップショット
- `src/life.ts`：会話・生活・探索・経済のルール
- `src/data.ts`・`src/data/dialogues.json`：人物・アイテム・レシピ・資源・台詞のデータ
- `src/renderer.ts`・`ui.ts`・`game.ts`・`controller.ts`：描画・画面・入力
- `src/save.ts`：A/B保存・検証・旧バージョン移行
- `vite.config.ts`：ビルドとオフラインキャッシュ生成

## v0.3での仕上げ

料理試作で選んだ魚を正確に消費し、戦闘の魔法・薬・攻撃に共通の入力間隔を適用しました。早送り中の強化失効、死亡後の疲労搬送による意図しない復活、修理材料、漁師の依頼、子供の特別な情報、靴の移動速度も調整しています。

地図には発見済みの建物・橋・祭壇と杭を表示します。ゲームパッドの十字キーで会話・メニューの選択肢を移動し、Aで決定、Bで戻れます。起動用JavaScriptの読込失敗時にも日本語の案内を表示します。保存形式はv2を維持し、不正な対象ID・生活値・魚影などの読込を拒否します。

## 配布と未検証の範囲

`npm run build` で生成した `dist/` 全体を静的ホスティングへ配置します。相対パスでGitHub Pagesのリポジトリ配下にも対応します。初回のオフラインキャッシュが終わる前に閉じた場合は、再びオンラインで開いてください。キャッシュや保存をブラウザが削除した場合もオンラインでの再取得が必要です。

**実機iPhone Safari／Android、物理ゲームパッド、長時間プレイのバランス確認は未実施です。** WebKitの追加取得は環境のネットワークポリシーによる403で実行できませんでした。必要な配布先は `cdn.playwright.dev` と `playwright.download.prss.microsoft.com` です。BGM／効果音は仕様書で任意のため未搭載です。

[検証記録・公開前の確認事項](docs/validation.md)に、実行済みの範囲と残りの実機確認を記載しています。初期版のため、地形・台詞・グラフィックは簡素なデータと描画で構成しています。

実装範囲と完成判定は[受け入れ状況](docs/acceptance.md)にまとめています。実機での必須確認が残るため、v0.3は完成候補として扱います。
