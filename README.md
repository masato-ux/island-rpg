# 無詠唱の漂流者

PCブラウザ／iPhone Safari向けの見下ろし2D RPG。[仕様書v1.0](docs/rpg_spec_v1.md)のフェーズAを段階的に実装しています。

## 現在遊べる流れ

1. 「最初から」で南海岸へ漂着する。
2. すぐ東のダンに近づき「調べる」。紙とペンを受け取る。
3. 少し北、中央の道沿いの草を「調べる」。安全な採集を体験する。
4. 西の家畜小屋付近へ移ったダンに戻り、家禽と一度だけ模擬戦。ここだけHP0でも気絶で済む。
5. 村中央の村長宅前のロアンに報告し、魔法の袋と魂の楔を受け取る。
6. メニューから「魂の楔で保存」。北口から草原へ行き、野ネズミ／森スライムと遭遇する。
7. 死亡時の「魂を戻す」、またはタイトルの「続きから」で保存時点へ戻る。

草原での戦闘は選択中も敵が攻撃します。攻撃／防御／逃走が使え、各行動の再入力は0.4秒後です。防御は次の1回のみ半減。撃破すると素材を得ますが、通貨は落ちません。最初の流木が武器代わりで、武器基本攻撃力2の仮パラメータです。HP回復・装備・成長は未実装なので、探索前の保存を推奨します。

## 実装内容

- TypeScript + Vite + Canvas 2D。ロジック・マップ・描画・保存処理を分離。
- 内部320×180、16pxタイル。画面内だけ描画し、整数倍表示を基本に狭い画面は縮小。
- 村・南海岸48×40／南部草原72×56、カメラ追従、半径5pxの衝突、0.25秒フェードで往復。
- キーボードとPointer Eventsによるタッチ長押し。4方向2コマ歩行、走る・忍び足。
- 実時間1秒＝ゲーム内10秒、08:00開始。タイトル／死亡画面／非表示中は停止。メニューと戦闘中は進行し、休止後の1フレームは0.1秒以内に制限。
- 野ネズミは近づくと逃げ、スライムは低速徘徊。草原には最大6体、討伐後はゲーム内30〜90分後に再出現。村にいる間は遠方の魔物が移動しない。
- 導入の草採集は2実秒で5ゲーム分を進行（村内の安全な一回限りのチュートリアル）。
- 乱数シードを保持。保存対象は現在実装している時刻、位置、向き、HP/MP、所持品、物語フラグ、魔物のHP／位置／再出現時刻／AIタイマー、逃走直後の猶予。
- localStorageのA/B二世代保存とチェックサム検証。破損時は最後の正常世代を読み込み、容量不足は案内。JSONの書き出し／読込と形式・バージョン・座標の検証。
- 初回描画検知、描画失敗時の文字案内、非表示・復帰時の入力と経過時間のリセット。

## 操作

- WASD／矢印：移動、Shift：走る、Alt：忍び足
- Z／Enter：調べる（ボタンにフォーカスがある場合はそのボタンを実行）
- C：メニュー、X／Escape：閉じる
- 左下の十字ボタン：タッチ移動。右下で調べる／メニュー／移動モード切替
- メニューは時間を止めません。戦闘に入ると閉じます。戦闘／採集／マップ切替中は保存不可

保存はブラウザごとです。ブラウザのデータを削除すると消えます。JSONを書き出して別途保管してください。JSON読込は現在の進行を置き換え、保存スロットも更新します。「最初から」だけでは以前の保存を消しません。

## 未実装の範囲

フェーズA全体の完成ではありません。NPCは現在ダンとロアンの導入用固定配置で、12人の日課移動・選択式筆談・任意のメモ・家畜小屋の室内と睡眠は次の実装範囲です。会話台本、正式な資源再生、装備耐久／魔法／XP成長、ショップ、空腹、病気、残りのマップも未実装です。HP／MP以外の生活数値を仮に動かしてはいません。導入の台詞は現在、メッセージ表示で進行します。

## 開発と検証

Node.js 24.19以上を推奨（単体テストはNodeのTypeScript直接実行）。

```sh
npm ci
npm start
```

Viteは全インターフェースの5173番で起動します。実機は同じネットワークのPCのIP／ポート、または静的ホスティングへアクセスしてください。開発サーバーには認証がありません。

```sh
npm run build
npx playwright install chromium
npm test
```

このクラウド環境では既存の `/usr/bin/chromium` を利用するため追加のブラウザインストールは不要。任意の実行ファイルは `CHROMIUM_PATH` で指定可能です。テストは単体11件と、PC／iPhone相当のChromiumでブラウザ16件を実行します。ブラウザテストはビルド済み `dist/` を5180番で配信します。先に `npm run build` を実行してください。

単体：時計の進行／停止、敵の攻撃、連打制限、防御、素材ドロップ、家禽の気絶と通常死亡、導入順序、乱数含む保存復元、破損世代・書込失敗・不正JSON、移動・マップ往復。
ブラウザ：描画とタッチ、入力解除、縦横表示、タイトルとメニューの時計、導入を実操作で完走→保存→JSON書出し→再読込、JSON読込→戦闘→死亡→保存への復元、保存機能が拒否された場合の案内と起動。スクリーンショットは `test-results/`。

Chromiumエミュレーションは実機検証とは異なります。公開前にiPhone Safari／Androidで画面回転、スリープ復帰、マルチタッチ、ファイル書出し／読込を確認してください。

## GitHubと配布

`dist/` を静的ホスティングへ配置できます。相対baseを設定済みでGitHub Pagesのサブパスにも対応します。ゲーム実行時は外部画像・CDN・APIキー不要ですが、オフライン再訪を保証するService Workerは未実装です。

```sh
git push origin HEAD:feat/browser-rpg-foundation
```

同じブランチを使うOpenのPRには追加コミットも反映されます。マージやWeb公開は別操作です。
