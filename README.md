# 無詠唱の漂流者

PCブラウザ／iPhone Safari向けの見下ろし2D RPG。仕様書v1.0に沿ったフェーズA・項目1（移動基盤）の実装です。

## 現在できること

- TypeScript + Vite + Canvas 2D。ロジック・マップ・描画を分離。
- 内部320×180、16pxタイル、画面内だけ描画。整数倍表示を基本に狭い画面では縮小。
- 村・南海岸48×40、南部草原72×56。カメラ追従、半径5pxの衝突。
- 村の北口／草原の南口で0.25秒のフェードと往復。幅3タイルのゲート。
- 4方向2コマ歩行。WASD／矢印、Shiftで走る、Altで忍び足。
- 左下のタッチ十字キー、右下の操作ボタンと歩く／走る／忍び足切替。
- 初回描画の検知、初期化／描画失敗時の文字案内、非表示中の更新停止、復帰時の経過時間リセット。

HUDのHP／MP／満腹／日付は初期値の表示のみです。調べる／メニューは現段階の説明表示です。NPC、室内、会話、ゲーム時間、戦闘、採集、睡眠、セーブは未実装であり、フェーズA全体の完成ではありません。建物は簡易外観です。

## 開発

Node.js 24.19以上を推奨（単体テストでNodeのTypeScript直接実行を使用）。

```sh
npm ci
npm start
```

Viteは全インターフェースの5173番で起動します。スマートフォン実機からは同じネットワークのPCのIP／ポートまたは静的ホスティングへアクセスしてください。開発サーバーには認証がありません。

## 検証と配布

```sh
npm run build
npx playwright install chromium
npm test
```

クラウド環境では既存の `/usr/bin/chromium` を使うためブラウザ追加インストールは不要です。任意の実行ファイルを `CHROMIUM_PATH` で指定可能。テストは単体3件と、PC／iPhone相当のChromiumでブラウザ8件を実行。ビルド済み `dist/` のサーバーをテスト専用5180番で自動起動します。

単体：マップ往復と安全な出現、海・建物の衝突、速度・フレーム上限、主道の到達性。
ブラウザ：描画ピクセル、キー・タッチ移動、解除・キャンセル、縦横画面、フォーカス／可視状態の変更、初期化失敗案内、実操作によるマップ往復。スクリーンショットは `test-results/` に生成。

Chromiumエミュレーションは実機Safariの検証とは異なります。公開前にiPhone Safari／Androidで回転、スリープ復帰、指離しとマルチタッチを確認してください。

`dist/` を静的ホスティングへ配置できます。Viteの相対baseを設定済みでGitHub Pagesのサブパスにも対応。ゲームの実行時は外部画像・CDN・APIキー不要ですが、オフラインでの再訪問を保証するService Workerは未実装です。
